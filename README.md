# Aprimore

# 🌱 Projeto Aprimore

O **Aprimore** é uma plataforma web desenvolvida para apoiar o desenvolvimento pessoal e acadêmico de estudantes universitários, promovendo o acompanhamento e a participação em atividades como **palestras, oficinas e rodas de conversa**.

O projeto foi desenvolvido com uma arquitetura full stack, utilizando Vue no frontend e Java com Spring Boot no backend, com comunicação por meio de uma API REST e persistência de dados em PostgreSQL.

## 🎯 Objetivo

O projeto Aprimore visa fomentar momentos voltados à discussão de **saúde mental**, **qualidade de vida** e **direcionamento nos estudos** de estudantes universitários, contribuindo para uma vivência acadêmica mais leve e equilibrada.

## Como executar

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
./mvnw spring-boot:run
```
